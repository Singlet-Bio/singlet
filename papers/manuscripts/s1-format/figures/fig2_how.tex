\caption{\textbf{How \sone{} stores single-cell counts.}
\textbf{(a)} A dataset is a manifest naming one immutable object per sample by its hash; gene vocabularies and
barcode whitelists live in shared packs.
\textbf{(b)} A sample object is a 64-byte header, a member table and bodies: a cells table and one count-matrix member
per modality; derivable tables become recipes verified on that sample.
\textbf{(c)} The header and member table locate every member; the manifest repeats their offsets.
\textbf{(d)} The counts member's prefix (header, chunk index, entropy tables, row keys) plans any read; chunks of
consecutive cells decode independently, so reading cells costs the prefix plus one range request per run of chunks.
\textbf{(e)} Inside a chunk, genes are numbered by detection frequency, each entry becomes a step symbol (plus a
residual unless its count is 1) coded with a table chosen by cell depth and position, and 32 rANS lanes write one
stream.}
\label{fig:how}
\end{figure*}
