\caption{\textbf{How \sone{} stores single-cell counts.}
\textbf{(a)} A dataset is a small manifest that points to one immutable sample object per sample. Gene identifiers and barcode whitelists can be moved into shared packs that a reader fetches once.
\textbf{(b)} A sample object contains a cells table and one matrix member per count modality. Everything that can be recomputed is replaced by a recipe that the writer has verified on that sample.
\textbf{(c)} A matrix member starts with a prefix (header, chunk index, entropy tables, row keys) that lets a reader plan any read; chunks of at most 49{,}152 non-zeros follow and decode independently, so any set of cells costs two range requests.
\textbf{(d)} The codec. (1--2) Rows are numbered by how many cells express them, so frequent genes come first and the gaps between a cell's non-zeros are small. (3) Each non-zero becomes one symbol (gap class and a flag for counts above one) and, for counts above one, a residual. (4) The cell's depth and the position in its list select a probability table. (5) Thirty-two interleaved static rANS lanes write one stream; decoding is branch-free table arithmetic that SIMD units run eight or sixteen lanes at a time.}
\label{fig:how}
\end{figure*}
