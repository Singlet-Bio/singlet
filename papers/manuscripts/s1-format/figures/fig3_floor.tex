\caption{\textbf{Little room is left for any lossless format.}
\textbf{(a)} Payload (row indices and values, without names) in bits per non-zero, median over matrices, as each idea is
added; whiskers, interquartile range. A strong general-purpose compressor on well-separated streams stops at
\nm{ladder-L3_gaps_leb_zstd19} bits; modelling the counts brings \sone{} to \nm{ladder-L4_s1_payload}. Dashed: the shortest
code length of four count models fitted on half of each matrix's cells and scored on the other half, charged nothing for
their own parameters (a reference, not a bound); it is a median of \nm{s1AboveFloorPct}\% below \sone.
\textbf{(b)} Where the \sone{} payload goes, by protocol class: the estimated entropy of the random sampling of each
cell's molecules (meaningful for UMI counts), which no lossless decoder can avoid; the remaining information about the
cell's expression profile; and \sone's margin above the best model. For UMI data sampling is a median of
\nm{samplingPctMedian}\% of the \sone{} payload. Per-model savings and a second compression pass: Supplementary
Fig.~\ref{fig:sfloor}; values per class in Supplementary Table~\ref{tab:floor}.}
