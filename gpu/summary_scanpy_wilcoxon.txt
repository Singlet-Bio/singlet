SCANPY WILCOXON RANK-SUM: EXACT ALGORITHM
Source: scanpy/tools/_rank_genes_groups.py (lines 277–364)

1. REFERENCE MODE
   Default: reference='rest' (one-vs-rest per group)
   Alt: reference='{group_name}' (specified group vs all others)
   → Controls whether wilcoxon() path (lines 286–326, one-vs-rest) or (lines 329–364, many-vs-many)

2. RANKING STRATEGY (lines 45–80, _ranks function)
   Per-gene ranking applied GLOBALLY across both group + reference cells combined:
   - Combine cells from test group + reference group (or all other groups if many-vs-many)
   - For each gene (chunked, max 10M cells per chunk): rank all cells' expression values
   - Ranking: pandas DataFrame.rank() (default ties='average')
   → Produces: average ranks, handling ties by averaging their rank positions

3. TIE HANDLING (lines 83–94, _tiecorrect function)
   Applied PER GENE after ranking:
   - Count tied groups: t_i = count of cells with tied expression value
   - Tie correction factor: T = 1 - Σ(t_i³ - t_i) / (n³ - n)
   - If tie_correct=False (DEFAULT): T = 1 (no correction applied)
   - If tie_correct=True: T computed, stored, used in variance (line 317/355)

4. TEST STATISTIC (one-vs-rest, lines 295–326)
   - Ranks summed for TEST GROUP ONLY (line 312): R_n = sum(ranks[0:n_active])
   - n_active = count cells in test group
   - m_active = count cells in reference group
   - W = R_n - (n_active * (n_active + m_active + 1) / 2)  [center by expected rank sum under null]
   - std_dev = sqrt(T * n_active * m_active * (n_active + m_active + 1) / 12)
   - z = W / std_dev (standard normal approximation, lines 320–322)

5. p-VALUE COMPUTATION
   - Two-sided: p = 2 * Phi(-|z|)  [using scipy.stats.distributions.norm.sf]
   - No continuity correction applied
   - Exact two-sided (not approximation; normal approximation used for large n)
   - If n_active ≤ 25 OR m_active ≤ 25: warning logged, but still uses normal approx (line 305)

6. EFFECT SIZE: log-fold-change (lines 452–463)
   - LFC = log2( (expm1(mean_group) + 1e-9) / (expm1(mean_rest) + 1e-9) )
   - expm1_func = np.expm1 by default (or expm1 with custom base if adata.uns['log1p']['base'] set)
   - expm1(x) = e^x - 1, so (expm1(x) + 1) = e^x
   - Formula: log2( e^(log_group) / e^(log_rest) ) = log2( e^(log_group - log_rest) )
   - If data is log-scale input: this recovers fold-change from log-differences
   - Scale: log base 2
   - Added 1e-9 to both numerator + denominator to avoid division by zero

7. CONSTANT EXPRESSION FILTERING
   - No filtering. All genes included (zeros in expression allowed)
   - NaN scores set to 0 after division by std_dev (line 323)

8. REFERENCE GROUP SPECIFICATION
   - reference='rest' (default): one-vs-rest per group (line 105, line 286 path)
   - reference='{group_id}': one-vs-one; use specified group as reference for all comparisons (line 286–326 path, ireference stored at line 156)
   - pts / pts_rest: fraction of non-zero cells (lines 204–205, 220–221)

KEY REFERENCE
- Mann & Whitney (1947) "On a test of whether one of two random variables is stochastically
  larger than the other" Ann. Math. Statist. 18(1):50–60
- scipy.stats.mannwhitneyu uses same normal approximation + tie correction (SciPy docs)
- scanpy uses rank sums directly (not U statistic), but mathematically equivalent

CRITICAL DIVERGENCE POINTS FOR GPU vs SCANPY
1. Tie averaging: scanpy uses average ranks (pandas .rank()); GPU likely uses midrank. Verify.
2. Tie correction: scanpy applies ONLY if tie_correct=True (default False). Is GPU including correction?
3. LFC scale: scanpy uses log2(ratio of expm1+1), not log1p(ratio). Verify GPU formula.
4. Normal approx only: no exact Wilcoxon test; always uses normal CDF for p-values.
5. All-gene ranking: ranks computed on FULL combined set, not per-group.
