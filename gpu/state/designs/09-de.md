## Algorithm

`de/wilcoxon.h` and `de/ttest.h` implement the two consensus DE methods per lit-scout. Both share the same input contract: a CSC sparse count matrix on device + cluster labels per cell + a target group (one-vs-rest or one-vs-one).

The pseudobulk NB GLM (DESeq2-like) is **deferred to cycle 17** (feature 15: donor-aware pseudobulk DE, exploiting singlify's `donor_assignments.tsv`). It is the singlet-gpu unique contribution and gets its own cycle.

### Wilcoxon (`de/wilcoxon.h`)

Per lit-scout consensus + ScaleSC + rapids-singlecell pattern: histogram-binned Wilcoxon with erfc p-value. The killer optimization is the **histogram-binned ranks** trick — instead of fully ranking each gene's values across all cells (O(C log C)), we discretize values into `B` bins (default B=4096), accumulate per-bin counts per cluster, then compute approximate rank sums in O(B). For million-cell scale, B << C and the speedup is dramatic.

Algorithm:

1. **Pass 1 — per-gene global histograms** (one block per gene):
   - Walk the gene's nonzeros (CSR view of the input — same trick as cycle 4 HVG).
   - For each nonzero `x_ig`, compute `bin = clamp(log1p(x) * scale, 0, B-1)`. The log1p binning gives high resolution near zero (where most counts live) and lower resolution at the high end.
   - Atomically increment `hist_global[g][bin]` and `hist_per_cluster[g][cluster_id[j]][bin]`.
   - Track per-gene per-cluster `n_nonzero` and `sum`.
   - The zero-count contributions are added in closed form per cluster post-pass (`hist_per_cluster[g][c][0] += n_zero_cells_in_cluster_c`).

2. **Pass 2 — per-gene per-cluster Wilcoxon U statistic** (one warp per (gene, cluster) pair):
   - From `hist_per_cluster[g][c]` and `hist_global[g]`, compute the rank sum for cluster `c`: `R_c = Σ_b bin_midrank(b) * hist_per_cluster[g][c][b]` where `bin_midrank(b)` is the midrank of bin `b` (the average rank of all cells in that bin assuming a uniform distribution within the bin).
   - U statistic: `U = R_c − n_c (n_c + 1) / 2`.
   - Tie correction: `T = Σ_b t_b³ − t_b` where `t_b = hist_global[g][bin]`. Apply standard Wilcoxon tie correction.
   - z-score: `z = (U − μ_U) / σ_U` where `μ_U = n_c · n_rest / 2`, `σ_U = sqrt(n_c · n_rest * (n_total + 1 − T_factor) / 12)`.
   - p-value: `p = erfc(|z| / sqrt(2))` for two-sided test. Use `erfcf` for fp32 stability.

3. **Pass 3 — log-fold-change** (one thread per (gene, cluster)):
   - `mean_in[g][c]` = `sum_per_cluster[g][c] / n_cluster_c`.
   - `mean_out[g][c]` = `(sum_global[g] - sum_per_cluster[g][c]) / (n_total - n_cluster_c)`.
   - `log2_fc[g][c]` = `log2((mean_in + 1e-9) / (mean_out + 1e-9))`.
   - For input matrices that are already log-normalized: the log2_fc is computed on the log-normalized values directly (the difference of means).

4. **Pass 4 — per-cluster ranking** (cub::DeviceRadixSort by `|z|` per cluster):
   - For each cluster, sort genes by `|z_score|` descending → top-N marker indices.
   - Output a `WilcoxonResult` per cluster: top-N genes, scores, log-fold-changes, p-values, adjusted p-values (Benjamini-Hochberg).

### t-test (`de/ttest.h`)

Welch's t-test, parametric, much faster (no histogram pass). For datasets where Wilcoxon is overkill or where speed dominates correctness.

1. **Pass 1 — per-gene per-cluster Welford** (one block per gene): compute `mean_in`, `mean_out`, `var_in`, `var_out` via the cycle-4 HVG sparse two-pass formula extended to per-cluster.
2. **Pass 2 — Welch t** (one thread per (gene, cluster)):
   - `t = (mean_in - mean_out) / sqrt(var_in / n_in + var_out / n_out)`
   - df via Welch–Satterthwaite.
   - p-value via `erfcf(|t| / sqrt(2))` (Gaussian approximation for fp32 stability — the exact Student's t CDF is hard on GPU; for large n the Gaussian limit is fine).
3. **Pass 3 — log-fold-change** (same as Wilcoxon).
4. **Pass 4 — top-N selection** via cub.

## Numerical stability

- **fp32 throughout**. Lit-scout: "fp32 vs fp64 fold-changes: log2(fold) stable at fp32 if counts > 10".
- **Welford / Kahan compensation** in pass 1 for high-count genes (cycle 4 pattern reused).
- **erfc for p-value underflow** — the lit-scout's "novel trick" #4. Use `erfcf` directly; do NOT compute via `1 - erf` (cancellation).
- **BH adjustment**: post-test, sort p-values per cluster, multiply by `n_genes / rank`, take cumulative min from the bottom.

## Memory layout

- Input: `DeviceCSC` (m × n) + `DeviceMemory<int> labels(n)` + `int n_clusters`.
- Workspace:
  - `hist_per_cluster[m][n_clusters][B]` — `4 * m * n_clusters * B` bytes. For m=30k, n_clusters=10, B=4096: 4.9 GB. **TOO BIG** — must tile by gene chunks.
  - Tile by gene chunks of `g_tile` rows: workspace = `4 * g_tile * n_clusters * B` bytes. For `g_tile = 1024`: 168 MB. Manageable.
  - `sum_per_cluster[m][n_clusters]`, `n_cluster[n_clusters]`: `4 * m * n_clusters + 4 * n_clusters` bytes. Tiny.
- Output: `WilcoxonResult[n_clusters]`, each containing `top_n` genes + scores + lfcs + pvals.

The histogram-binned approach trades memory for runtime. Tiling by gene chunks keeps memory bounded at ~200 MB regardless of m.

## Streams

One stream, caller-provided. Pass 1 (histogram) and pass 2 (statistic) chain on the same stream.

## Out-of-core

For multi-chunk inputs (cycle 7 `streamed_pipeline`):
- **Wilcoxon**: per-chunk histograms accumulate into the global `hist_per_cluster`. Single pass over the data. The bins are per-gene global, so the histogram structure is shared across chunks.
- **t-test**: per-cluster per-gene Welford accumulators merge across chunks.

Both methods are streaming-friendly. Document the integration with `streamed_pipeline.h` for cycle ≥ 12.

## Determinism

- Histogram atomic adds are NOT deterministic on their own. The `deterministic` flag uses cub's segmented scan for the histogram instead — slower but bit-reproducible.
- Welford merge across chunks is deterministic given fixed chunk order.
- Top-N selection via cub::DeviceRadixSort is deterministic with stable tie-breaking.

## Correctness test spec

Tests:
- `tests/de_wilcoxon_correctness.cpp`
- `tests/de_ttest_correctness.cpp`

Reference: scanpy `sc.tl.rank_genes_groups(adata, groupby='leiden', method='wilcoxon')` and `method='t-test'` in subprocess.

Test cases (each test):
1. **Tiny synthetic**: 500 × 200 fixed-seed CSC with planted differential genes (50 genes upregulated in cluster 0, 50 in cluster 1, etc.). Run our DE, then scanpy. Compare top-50 marker indices per cluster — Jaccard ≥ 0.90. Spearman ρ on log2_fc ≥ 0.98.
2. **GSM4037629 with k=10 leiden clusters**: real data path. Same comparison.
3. **Determinism**: run twice with `deterministic=true`. Bit-identical.
4. **Edge cases**: 0 cells in a cluster, 0 nonzero counts in a gene, single cluster (all-vs-nothing).

Tolerance:
- Marker gene Jaccard ≥ 0.90 (rank-sensitive)
- log2_fc Spearman ρ ≥ 0.98
- p-value rank Spearman ρ ≥ 0.95
- Determinism: bit-identical with `deterministic=true`

## Risks

1. **Histogram tile memory**: 30k genes × 10 clusters × 4096 bins × 4 bytes = 4.9 GB without tiling. Tiling by gene chunks of 1024 brings it to 168 MB. Document the tile size auto-tune.
2. **erfc precision**: `erfcf` is ulp-accurate in fp32 but can underflow for very extreme z-scores (|z| > 6). Use the asymptotic expansion for large |z|.
3. **Wilcoxon binning approximation error**: the binned rank sums are approximate. Lit-scout: "wilcoxon_binned" approximation has been validated by ScaleSC + rapids-singlecell on real data — error is O(1/B). For B=4096, the rank error is sub-pixel.
4. **Cluster size edge cases**: empty clusters, single-cell clusters. Handle gracefully (return null result for the cluster).
