Sample QC Report¶

Generate a complete QC report from a single singlify output directory using singlet.load_dir(). The function returns AnnData with pre-computed UMIs, genes, MT%, doublet scores, cell cycle, and ancestry.

Sample: GSM3573650 (human bone marrow, ~75K cells)

%matplotlib inline
import singlet
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['figure.dpi'] = 120

# One-call load with all QC
adata = singlet.load_dir('/mnt/projects/debruinz_project/singlify_pipeline/quant/scrna/GSE125/GSE125416/GSM3573650')
print(f"Loaded: {adata.n_obs:,} cells × {adata.n_vars:,} genes")
print(f"\nPer-cell annotations (adata.obs):")
for col in adata.obs.columns:
    dtype = adata.obs[col].dtype
    print(f"  {col}: {dtype}")

    ax.set_visible(False)

# Violin plots for key metrics
fig, axes = plt.subplots(1, 3, figsize=(13, 4))

metrics = ['total_umis', 'total_genes']
if 'doublet_score' in adata.obs.columns:
    metrics.append('doublet_score')

for ax, metric in zip(axes, metrics):
    data = adata.obs[metric].dropna()
    parts = ax.violinplot([data], positions=[0], showmedians=True)
    parts['bodies'][0].set_facecolor('#3b82f6')
    parts['bodies'][0].set_alpha(0.7)
    ax.set_ylabel(metric)
    ax.set_xticks([])
    ax.set_title(f'{metric}\n(median={data.median():,.1f})')

plt.tight_layout()
plt.show()

Summary¶

singlet.load_dir() returns a fully-annotated AnnData object with:

Annotation Source Description
total_umis gene_counts.1pz Total UMIs per cell
total_genes gene_counts.1pz Genes detected per cell
doublet_score doublet_scores.tsv UMI-based doublet probability
doublet_class doublet_scores.tsv singlet/doublet classification
cell_cycle_phase cell_cycle_scores.tsv G1/S/G2M phase
mt_pct cell_qc_metrics.tsv Mitochondrial percentage

One function call = complete QC-ready AnnData for downstream analysis.
