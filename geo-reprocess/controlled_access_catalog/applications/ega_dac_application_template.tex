\section{Research Purpose}
% ══════════════════════════════════════════════════════════════════════════

\subsection{Scientific Justification}

We are constructing a comprehensive, splicing-resolved single-cell
transcriptomic reference by reprocessing raw FASTQ files from all
available single-cell and single-nucleus sequencing studies into
harmonized count matrices. These matrices are decomposed via
\textbf{Non-Negative Matrix Factorization (NMF)} to identify universal
gene expression programs that capture the full diversity of human
cellular states.

The requested datasets are essential because they contain
\textbf{unique tissue types, disease contexts, and patient populations}
not represented in publicly accessible repositories (GEO, ENCODE). The
European-origin cohorts in EGA are particularly valuable for ensuring
that the reference captures population-level variation in gene programs.

\subsection{Specific Use of Data}

\begin{enumerate}[nosep]
    \item \textbf{Reprocessing:} Raw FASTQ files will be aligned to
          GRCh38 using STARsolo with splice-aware quantification,
          producing per-sample count matrices with spliced/unspliced
          layers.

    \item \textbf{NMF Decomposition:} Count matrices will be integrated with
          our existing catalog ($\sim$180K public samples) and
          decomposed into a genes-by-factors matrix $\mathbf{W}$ and a
          factors-by-cells matrix $\mathbf{H}$.

    \item \textbf{Public Output:} Only the non-identifiable
          $\mathbf{W}$ matrix (gene loadings, a population-level
          gene-program dictionary) and k-anonymized summary statistics
          will be released publicly. No individual-level data is
          distributed.
\end{enumerate}

\subsection{Non-commercial Declaration}

This research is conducted in a \textbf{non-commercial, academic
capacity}. No individual-level data, derived products containing
individual information, or sequence data will be sold, licensed, or
transferred to commercial entities.

\section{Privacy and Ethical Considerations}
% ══════════════════════════════════════════════════════════════════════════

\subsection{No Re-identification}

We will make no attempt to re-identify study participants from the
genomic data. Metadata is used solely for annotating NMF factors
(e.g., associating factors with tissue types or disease categories)
at the aggregate level.

\subsection{Output Privacy}

The $\mathbf{W}$ matrix is a population-level parameter containing no
individual data. Each column represents a gene co-expression program
learned from millions of cells collectively. Removing any single donor
changes $\mathbf{W}$ by $O(1/N)$, making individual contributions
non-recoverable.

Summary statistics are released only after k-anonymization ($k \geq 10$
donors per group).

\subsection{GDPR Considerations}

As the data originates from European subjects and is processed in the
United States:
\begin{itemize}[nosep]
    \item Processing is conducted under the \textbf{scientific research
          exemption} (GDPR Article 89).
    \item No individual-level data leaves the secure compute
          environment.
    \item A \textbf{Data Processing Agreement (DPA)} can be executed
          with the data controller if required.
    \item The university maintains Standard Contractual Clauses (SCCs)
          for EU--US data transfers as required post-Schrems~II.
\end{itemize}
