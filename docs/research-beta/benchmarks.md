# Public benchmarks: research-beta handoff (2026-10-26)

**State.** The benchmark program behind beta.singlet.bio/benchmarking: a results contract, a cohort, a Clipper harness,
two finished capabilities (chromosomal sex, genetic ancestry) and a downloadable notebook.

**Where.** Branch `claude/bench-public-cohort-485cf7`, draft PR Singlet-Bio/singlet#40 (not merged). Everything is
under `bench/public/`; start with `bench/public/README.md`.

## 1. Results contract (`bench/public/CONTRACT.md`, schema 1.1.0)

- **Files.** One JSON per capability in `bench/public/results/<id>.json`, plus `index.json`, which
  `python bench/public/contract.py index bench/public/results` generates. There are 22 capability ids, each with an owner,
  listed in `contract.CAPABILITIES`.
- **Validation.** `contract.py` is the authority: the validator, the pass rules, the index and the reproduction diff, all
  standard library only. The JSON Schemas for the website are in `bench/public/schema/`.
- **Pass rules.** `pass` is computed, never hand-written, from one of `match_or_beat`, `threshold` or `equivalence`.
  - A comparison cannot be marked informational.
  - A tolerance or threshold needs a stated rationale.
  - A capability passes only when its document is final and every gating metric passes.
- **What 1.1.0 added (Zach's decisions):**
  - **Real data only.** Each dataset declares a `data_kind` (real, derived or simulated) that must match the cohort.
    Derived or simulated metrics need `corroborated_by` pointing at real-data metrics, and a capability needs at least
    one real gating metric.
  - **Pareto figures.** Quality is plotted against runtime. Runtime stays a resource, never a gate.
  - **`reach[]`**: what each tool can produce at all.
  - **10x comparators** are 10x's published outputs, with their version and URL.
- **Tests.** `tests/python/test_bench_public_contract.py`, 23 tests.

## 2. Cohort (`bench/public/cohort.tsv`, generated by `make_cohort.py`; reasoning in `cohort.md`)

- **Size.** 52 datasets with accessions and URLs verified against 10x, GEO, ENA and Zenodo. Each row records its truth,
  licence, data kind, capabilities and tools.
- **Budget.** The core tier is about 215 task-hours, roughly 18 h at 12 concurrent 16-thread tasks
  (`python bench/public/cohort_plan.py`).
- **Not public.** The human lymph node Visium set has no public reads; `visium_ffpe_human_breast` replaces it.
- **Derived rows.** `mage150` (MAGE bulk RNA thinned to single-cell depth) and `lcl_gse230239` (in-silico pool) are
  derived. Real data backs them: `osorio2019_lcl_mix` and `atlas_selfreport`.

## 4. Results so far

**Chromosomal sex** (`results/chromosomal-sex.json`, draft): all 5 gating metrics pass. 171 real samples from 19 GEO
studies whose metadata records sex, 472,363 cells, all on the atlas's current counts.

| metric | Singlet | cellXY | XIST/chrY rule |
|---|---|---|---|
| samples called correctly | 0.971 | 0.819 | 0.971 |
| cells labelled correctly | 0.970 | 0.680 | 0.506 |
| cells labelled | 0.998 | 0.879 | 0.519 |
| precision on labelled cells | 0.972 | 0.773 | 0.976 |

- Precision passes only within the paired-bootstrap noise margin, which is pre-declared and applied to every per-cell
  metric.
- Five samples are called against their GEO sex by every tool; they are probably metadata errors.

**Genetic ancestry** (`results/genetic-ancestry.json`, draft): 8 of 11 gating metrics pass, 3 fail. 150 MAGE
individuals from 26 populations, read depths 0.5M / 2M / 8M pairs. The reference is leave-out: the test individuals were
removed for every tool (Singlet's allele frequencies, somalier's labels, and peddy's background via
`sexancestry/peddy_leaveout.py`). The leave-out did not change peddy, so its lead at 8M is real.

| metric (0.5M / 2M / 8M) | Singlet | somalier | peddy |
|---|---|---|---|
| most likely group correct | 0.927 / 0.933 / 0.933 | 0.573 / 0.887 / 0.920 | 0.847 / 0.900 / **0.993** |
| published label correct ('admixed' counts as wrong) | 0.86 / 0.86 / 0.86 | 0.573 / 0.887 / 0.920 | 0.847 / 0.900 / 0.993 |
| named calls correct | 1.00 / 1.00 / 1.00 | as above | 0.907 / 0.944 / 1.00 |

- **What fails.** The published label at 2M and 8M, and the most likely group at 8M. Singlet wins at 0.5M, the depth of
  a typical single-cell donor, and its named calls are never wrong.
- **What drives it.** 15 of 30 AMR individuals (plus 3 SAS and 2 AFR) are labelled "admixed" (q < 0.8), and at full
  depth peddy's PCA + SVM separates super-populations better.
- **Options for Zach:**
  - keep the failures;
  - recalibrate q_min on data other than MAGE;
  - pre-register "admixed" as correct for AMR;
  - improve the model at depth (e.g. a PCA/SVM-style classifier on the same panel).
- **somalier varies between runs** (0.57-0.62 at 0.5M).
- **Self-report check passes.** 21 atlas donors with self-reported ancestry in GEO: every named call is consistent with
  the reported group (1.00 against a 0.9 bar).
- **Bulk donor sex.** Singlet gets 0.90 right. The other 15 are female cell lines with XIST and Y-homolog reads, called
  ambiguous; this is recorded as a caveat.

## 6. Lessons

- **Bash on Windows-written TSVs.** `read -a` collapses empty fields, so `cohort_row` uses awk instead. Scripts need LF
  line endings; there is a `.gitattributes`.
- **sbatch copies the script at submit time.** Sync the worktree before submitting, not with `--dependency`.
- **Clipper limits.** The per-user node limit blocks `short-cpu`, so use `scavenger --requeue`. Download with NCBI
  prefetch; `fastq-dump -X` streaming and EBI are too slow.
- **Every reference panel must leave out the test individuals.** Leakage showed up as peddy reaching 0.993.
- **Check that the comparator is used as its authors intend.** cellXY's calls from X-escape genes on low-depth cells are
  its real behaviour. Its trained model needs `caret` loaded.
